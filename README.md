## 🚀 Proyectos de ingeniería

### 1. Sistema automatizado de dosificación y embolsado

**Tecnologías:** Arduino Opta · C/C++ · Neumática

Proyecto de automatización orientado a optimizar el llenado y sellado de bolsas mediante la integración de sensores, actuadores eléctricos y neumáticos.

- Desarrollo de diagramas de flujo y pseudocódigo para definir la secuencia de operación.
- Programación de la lógica de control en C/C++ para Arduino Opta.
- Diseño conceptual de la integración de sensores y actuadores.

### 2. Prototipo de secado de maíz con monitoreo y control

**Tecnologías:** Arduino · LabVIEW · DHT22 · Control On-Off

Desarrollo de un prototipo para monitorear y regular las condiciones de temperatura y humedad durante el secado de maíz.

- Adquisición de datos de sensores mediante Arduino.
- Implementación de una estrategia de control On-Off.
- Integración de LabVIEW para la lógica de control, visualización de variables y monitoreo.
- Exploración de soluciones de instrumentación y automatización aplicadas a procesos agroindustriales.
